# Karigar.ai PWA Icons

This directory contains PWA icons for the Karigar.ai application.

## Required Icons

The following icon sizes are required for PWA installation:

| Size | Filename | Purpose |
|------|----------|---------|
| 72x72 | icon-72x72.png | Small devices |
| 96x96 | icon-96x96.png | Medium devices |
| 128x128 | icon-128x128.png | Google Play |
| 144x144 | icon-144x144.png | Windows tile |
| 152x152 | icon-152x152.png | iPad |
| 192x192 | icon-192x192.png | Android |
| 384x384 | icon-384x384.png | High DPI |
| 512x512 | icon-512x512.png | Play Store |

## Icon Design

The icon should feature:
- A circular background with a gradient (cyan to teal)
- A central wrench/tool symbol representing "karigar" (craftsman)
- Clean, flat design suitable for various backgrounds
- White foreground on dark background

## Generation

To generate the icons from the SVG source:
1. Open `icon.svg` in a vector graphics editor (Figma, Inkscape, etc.)
2. Export at each required size as PNG
3. Ensure transparent background

Or use an online tool like:
- https://cloudconvert.com/svg-to-png
- https://realfavicongenerator.net/
